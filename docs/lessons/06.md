# 06 · The app UI

`/debug` is GIVEN and ugly on purpose: it proves the pipeline. `/app` is yours.

Minimum flow:

1. Deposit from alice (or the connected key) for the fixed denomination.
2. Save the note (download / copy the 64-byte encoding). Without the note the
   money is gone.
3. Fund a fresh address via Friendbot (`POST /api/fund`).
4. Prove withdraw and send it, paying the fresh address.

## GAP-6

Replace the blank shell in `apps/web/src/pages/AppPage.tsx`. Named test:
`app: deposit→withdraw`.

## Hints

<a id="hints"></a>

**Hint 1 — concept.** The UI is a note wallet plus two contract calls. The
note never goes on-chain.

**Hint 2 — shape.** Three panels: balances / deposit, notes list, withdraw.
Call the API for Friendbot and proving; call Soroban for deposit/withdraw
using generated bindings in `bindings/`.

**Hint 3 — near-code.** `Button` lives in `apps/web/src/components/ui/button.tsx`.
`encodeNote` / `decodeNote` are GIVEN. After GAP-1, `commitment(note)` gives
the deposit argument. Look at `/debug` for how the API is called. Do not
block the whole page on OpenRouter.
