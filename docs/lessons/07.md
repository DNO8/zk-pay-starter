# 07 · The OpenRouter step

The event requires an OpenRouter call **in the payment flow**, visible in
logs. The stub at `POST /api/ai/complete` already talks to OpenRouter with a
small model and `max_tokens: 300`. `POST /api/pay/ai-step` is the hole.

Ideas that count: parse a payment request ("send 10 to a fresh address"),
check a memo, explain a successful withdraw in one sentence. Use the stub
`chat()` helper. Log the model and a short result.

## GAP-7

Wire `chat()` into deposit or withdraw and make it visible. Named test:
`api: openrouter step logged`.

## Hints

facilitator must *see* the call.

**Hint 2 — shape.** In `/pay/ai-step` (or inside withdraw), call `chat(prompt)`,
`log(...)`, return `{ model, text }`. Hit that endpoint from the UI when the
user withdraws.
