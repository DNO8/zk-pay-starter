# 01 · Commitments and notes

A **note** is a bearer secret: whoever knows `(nullifier, secret)` can spend it.

```
commitment     = Poseidon₂(nullifier, secret)
nullifierHash  = Poseidon₂(nullifier, DOMAIN_NULLIFIER)   # DOMAIN_NULLIFIER = 1
```

The contract stores only `commitment` (in the Merkle tree). At withdraw time it
sees `nullifierHash`, never the note. Anyone can recompute the commitment from
the note; nobody can go backwards from the commitment.

Poseidon parameters live in `packages/shared/poseidon.params.json` (single source
of truth). Use `hash2` from `@zk-pay/shared`. Do not invent constants.
